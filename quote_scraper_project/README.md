# Quote Scraper & Analyzer

## 📌 Project Description

This project is a Python web scraper that collects quotes, authors, and tags from a website and saves the data into a CSV file.

## 🚀 Features

* Scrapes multiple pages automatically
* Extracts quote text, author, and tags
* Converts tags into clean, readable format
* Saves data into a CSV file
* Displays total quotes and pages scraped

## ▶️ How to Run

1. Install required libraries:
   pip install requests beautifulsoup4

2. Run the scraper:
   python scraper.py

3. Check the generated CSV file in your project folder

## 🛠️ Technologies Used

* Python
* Requests
* BeautifulSoup
* CSV
